# 本地视频制作与审片

视频试点将制作阶段挂到已有的协作 Run 上。开始前先创建一个专用素材目录，将允许导入的文件放入其中。用 `STUDIO_VIDEO_INPUT_ROOT` 指定目录后启动 Studio，在主页创建一个协作，再进入 `/video.html` 为该协作填写制作说明。

## 阶段与交接

制作说明（brief）通过后进入脚本阶段。脚本分别供分镜和音频使用，分镜交给视觉制作，最终剪辑同时依赖音频与视觉两个上游。页面按阶段显示角色、所需输入、预期产物和工具状态。

点击「加入任务」将阶段加入当前 Run 的任务队列。上游产物须已接收且通过完整性校验。任务完成后，用「导入产物」选择专用输入目录中的文件路径。服务以 SHA-256 保存文件快照，后续阶段引用该摘要。已接收的产物固定，修订时创建新的制作任务。

当前音频、视觉生成和剪辑适配器标记为待接入。可使用自己的制作工具，再通过阶段页面交接文件。已有 MP4 也可以直接导入审片。

## 成片审核

在成片页面预览当前版本并运行本机技术质检。macOS 探针利用 Swift 与 AVFoundation 读取视频和音频轨道，检查解码、时长和覆盖范围。审片者观看并听完该版本后，可以填写意见并选择通过或退回；同意记录要求先通过技术检查。确认时校验文件摘要，文件完整性失效会撤销已有记录。页面保存审片决定，平台发布仍由使用者另行处理。
