# 通过 Orchestrator 对话管理工作流

在当前协作的 Orchestrator 对话框发送消息。为 Orchestrator 选择支持工具调用的 DSH 模型后，可以用自然语言查看模板、启动工作流、查看本协作的执行进度和提出画布修改。离线演示使用固定对话脚本，体验这些操作时可以直接使用工作流页。

| 可以这样说 | 实际操作 |
| --- | --- |
| “列出可以启动的工作流，告诉我‘资料核验’最新版有哪些节点和依赖。” | 读取可用的已发布模板和指定版本的画布。 |
| “在这个协作启动‘资料核验’第 2 版。” | 在当前 Run 启动指定版本，沿用模板的 Agent 绑定、输入输出检查和人工放行条件。 |
| “这个协作有哪些流程在运行？哪一步在等我审阅？” | 查看当前 Run 的实例，列出各节点的执行轮次和状态。 |
| “把‘资料核验’最后一个节点改为人工审核，保留其他节点和规则，给我看草稿。” | 在同一模板中保存草稿。打开工作流页审阅节点、连线和规则，点击发布后形成可启动的新版本。 |

总编从最新已发布版本提出修改。已有未发布草稿或查看后版本发生变化时，工作台会提示先审阅已有修改。已启动的实例继续使用其原版本。聊天工具只交给直接处理用户消息的 Orchestrator。节点任务、Manager 和 Worker 无权调用，人工审核和模板发布由用户在工作流页完成。
